# 🕵️ AI Code Detective

## Project Overview

AI Code Detective is an interactive, AI-powered coding challenge application designed to help beginners improve their debugging and problem-solving skills.

Users are presented with coding problems, receive progressive hints, select the correct solution from multiple options, and receive an instant score based on their performance.

## Key Features

- 🎯 Beginner, Intermediate, and Advanced difficulty levels
- 🐛 Interactive code debugging challenges
- 💡 Progressive hint system
- 🧩 Multiple-choice code solutions
- ✅ Instant answer validation
- 📊 Performance and score tracking
- 🏆 Final Detective Report
- 🤖 Generative AI-powered challenge experience
- 💻 Built using Kimi K3
