# AI Resume Assistant

## Project Overview

AI Resume Assistant is a Generative AI project designed to help users create and improve professional resumes using AI.

## Objective

The main objective of this project is to use Generative AI to generate professional resume content based on user-provided information.

## AI Tool Used

- Claude AI

## Features

- Generates professional resume content
- Helps improve resume descriptions
- Creates structured resume sections
- Uses AI-generated suggestions
- Saves the generated resume output

## Files

- `prompt.txt` – Contains the prompt used for the AI.
- `resume_output.txt` – Contains the generated resume output.
- `Claude_output.png` – Screenshot of the AI-generated result.
- `README.md` – Project documentation.

## Prompt

The project uses a structured prompt to instruct the AI to create clear, professional, and well-organized resume content.

## Output

The generated resume content is saved in `resume_output.txt`.

## Conclusion

This project demonstrates how Generative AI can be used to assist users in creating professional resume content efficiently.
